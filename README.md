# COMP9444 Neural Networks & Deep Learning - 2024 T3

## Course Overview
COMP9444 focuses on neural networks and deep learning, covering the fundamentals and applications of these techniques. The course teaches how to build and train deep learning models, including neural networks, convolutional networks (CNNs), and recurrent networks (RNNs), with hands-on projects and assignments.

## Key Topics
Neural Networks & Deep Learning basics
Convolutional Neural Networks (CNNs) and Recurrent Neural Networks (RNNs)
Training and optimization techniques (e.g., backpropagation, gradient descent)
Regularization methods (e.g., dropout)
Practical applications: image recognition, natural language processing, and reinforcement learning.
